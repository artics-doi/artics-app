# v1.3.7 の本番反映

この手順は、公開する人が本番へ出すとき用です。この変更を入れただけでは、本番の関数と Hosting はまだ v1.3.6 のままです。

プロジェクト ID は `company-chat-a9cf0` です。必要な権限は v1.3.6 のときと同じです。Firebase のオーナー、または Firebase Admin で、関数のデプロイと Hosting の公開ができるアカウントです。

## この版で出すもの

| 対象 | この版 |
|---|---|
| Functions `fetchLinkPreview` | 出す。タイトルが空、またはサイト名だけのページでも、サイト名を返すようにした |
| Web 版 Hosting | 出す。カードの表示と、アプリ同梱の更新ノートはこちらに入る |
| 更新専用サイト | 出す。Windows 版 v1.3.7 のインストーラー |
| Firestore ルール | 変えない |
| Firestore インデックス | 変えない。`firestore:indexes` は出さない |
| Storage ルール | 変えない |
| GitHub Release | 作らなくてよい。v1.3.6 を入れた端末は更新専用サイトを見ている |

更新ノートの正本は `src/data/releaseNotes.ts` です。アプリの「設定」を10回クリックする編集画面は外しました。Firestore の `settings/releaseNotes` は、同梱に無い過去の版を1回だけ読み、下に足すために残しています。手で保存し直す必要はありません。

プレビューは送信時の1回だけです。メッセージへの保存もこれまでと同じ1回です。失敗したとき、または社内アドレスのときは、これまで通りリンクだけを表示します。過去のメッセージは取り直しません。

## 出す順番

1. このコミットを checkout し、`package.json` の `version` が `1.3.7` であることを確認します。

2. プレビュー関数を先に出します。Web 版やデスクトップ版より先です。関数が古いままだと、タイトルの無いページはカードが付きません。

```bash
npx firebase deploy --only functions:fetchLinkPreview --project company-chat-a9cf0
```

関数をまとめて出すコマンドは使いません。

3. Web 版を出します。`npm run build` の `dist/` を使います。`npm run build:electron` のあとの `dist/` は使いません。

```bash
npm ci
npm run build
npx firebase deploy --only hosting --project company-chat-a9cf0
```

4. Windows（Node.js 22）でインストーラーを作ります。Linux からのクロスビルドは使いません。

```bash
npm ci
npm run build:electron
```

`release/win-unpacked/resources/app-update.yml` が次であることを確認します。

```yaml
provider: generic
url: https://company-chat-a9cf0-updates.web.app/
useMultipleRangeRequest: false
```

5. 更新ファイルを更新専用サイトへ出します。

```bash
npm run stage:desktop-updates
```

PowerShell:

```powershell
$env:ARTICS_DEPLOY_DESKTOP_UPDATES = '1'
npm run publish:desktop-updates
```

6. 認証なしで取れることを確認します。`version` が `1.3.7` であること。

```bash
curl -fsS https://company-chat-a9cf0-updates.web.app/latest.yml
curl -I https://company-chat-a9cf0-updates.web.app/ArticsChat.Setup.1.3.7.exe
curl -I https://company-chat-a9cf0-updates.web.app/ArticsChat.Setup.1.3.7.exe.blockmap
```

7. v1.3.6 の PC で「アップデートを確認」を押します。設定の「現在のバージョン」が v1.3.7 になり、更新ノートの先頭が「2026/10/22：v1.3.7：リンクの表示を改善」なら完了です。

GitHub Release を作る場合は、上の Firebase 公開のあとです。v1.3.4 以前の端末が残っていると、その端末が GitHub 上の v1.3.7 へ直接飛びます。残っている間は作りません。作るときは次です。

```bash
gh release create v1.3.7 release/latest.yml release/ArticsChat.Setup.1.3.7.exe release/ArticsChat.Setup.1.3.7.exe.blockmap --title "v1.3.7" --notes-file docs/release-notes/v1.3.7-github.md --repo artics-doi/artics-app
```
