## ArticsChat v1.3.3

### 変更内容

- 工程管理に通知機能を追加。メンバーごとに通知のON・OFFと「新タスク作成／未着手／進行中／完了／保留」の通知対象アクションを設定できます。初期設定はOFFです。
- 通知を有効にした工程管理メンバーへ、担当者に関係なく全プロジェクトのタスクの動きを通知します。
- Windows版の工程管理通知を紫色のカードで表示し、チャット・行動予定表の通知と見分けやすくしました。通知から対象タスクを開けます。
- 過去のチャット履歴の読み込みを新着として数えたり、最下部へ強制スクロールされたりする問題を修正しました。

### アップデート方法

「設定」→「アップデートを確認」、またはアプリを起動し直してアップデートしてください。
