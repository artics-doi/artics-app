## ArticsChat v1.3.4

### 変更内容

- 完了タスクのチェック操作に「完了承認」通知を追加しました。チェック解除では通知しません。
- メンバー管理の通知ON／OFFを「通知設定」に変更し、受け取るアクションを選べるようにしました。
- 通常の通知先を、そのタスクの担当者へ変更しました。
- 複数人を追加・解除できる「タスク進捗管理者」欄を追加しました。管理者は担当や個別設定に関係なく、全プロジェクトの全6種類の通知を受け取ります。
- 担当者と管理者の重複通知を防ぎ、担当未設定の場合は管理者だけへ通知します。

### 補足

従来の通知ON／OFFは廃止され、担当者向けのアクション選択は引き継がれます。以前OFFだった方も、担当タスクの選択済みアクションを受信します。管理者は自動では追加されません。端末・OS側の通知許可は必要です。

Windows版は「設定」→「アップデートを確認」、またはアプリを起動し直して更新してください。
