## ArticsChat v1.3.5

### 変更内容

- Windows 版の自動更新の取得先を、GitHub Releases から Firebase Hosting の更新専用サイトへ変更しました。
- すでに入っている v1.3.4 以前は、この v1.3.5 をこれまで通り GitHub から受け取ります。v1.3.5 を入れたあとの更新は、新しい取得先を見ます。

- メッセージの一部だけを選んでコピーできるようにしました。

### 補足

更新後は、設定の「現在のバージョン」が v1.3.5 になっていることを確認してください。追加の修正は、この一覧に箇条書きを足してください。
