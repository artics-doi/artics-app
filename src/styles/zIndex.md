# Z-Index ガイドライン（M-4）

UI レイヤー順序を統一する。新規 CSS でこの順序を逸脱しないこと。

| 用途 | z-index | 例 |
|---|---|---|
| グローバルトースト | 9999 | `Toast.module.css` |
| PWA 更新プロンプト | 10000 | `PWAUpdatePrompt.module.css` |
| 画像プレビューモーダル | 2000 | `ImagePreviewModal.module.css` |
| 一般モーダルオーバーレイ | 1000 | Chat / Home / Login / Memo モーダル |
| ドラッグオーバーレイ | 1000 | Chat の D&D |
| ポップオーバー / メニュー | 100 | Chat のメニュー / リアクションピッカー |
| 補助オーバーレイ | 50 | Chat メニュー閉じる用 |
| 通常要素のレイヤー | 1〜20 | StatusDot / Memo のピン留めバッジ等 |

## ルール
- 新規モーダルは `z-index: 1000` を使用する
- 新規メニューは `z-index: 100` を使用する
- トーストより上に出すべき要素は出現しない想定（更新プロンプトは例外）
- 値は CSS Modules 内で直書き OK（共通定数化は将来検討）
